# 界面与验收

蓝白中性管理界面，桌面左导航、手机顶部与横向导航；计划和工单用状态、数量、进度区分。错误应在表单旁显示，禁用未满足条件的动作。

工作台先展示服务端统计的进行中计划、待完成工单与待审核报工，再并列展示生产进度和近期工单，近期计划放在下一层；入口按角色跳转到相应业务页面，审核产量与目标数量仅在进度区呈现。物料档案和 BOM 版本列表共用搜索、状态和清除筛选的控件，搜索按钮和状态选择保持统一高度，窄屏时换行且按钮文字不折行。模型接入只在设置页分类中显示，不占用业务侧栏菜单。

账号信息和设置入口位于侧栏底部；头像菜单提供设置和退出登录，齿轮直接打开设置页。设置页包含账号与安全，管理员另可进入模型接入；修改密码后重新登录。成员管理包含搜索、分页、内置角色说明、角色调整和启停；角色调整或停用后撤销该成员当前会话，至少保留一位在职管理员。角色权限在服务端固定，不提供自定义权限编辑。

验收路径：计划员先创建成品、半成品及组件档案；在 BOM 搜索下拉中选成品和组件，创建并发布两级 BOM；计划从档案选择产品和 BOM，核对损耗率、多级展开与汇总物料数量；发布新版本后旧计划需求不变。停用已发布 BOM 所用物料应被拒绝，修改物料名称不改旧 BOM 快照。随后创建并发布计划、下达工单；操作员登录提交合格与不良数；主管登录审核，刷新后工单和计划进度变化；超量报工应被拒绝；另一个操作员无法读取或修改该工单；拒绝报工后产量不变。循环 BOM 应拒绝发布。数据在重启后保持。

开源部署验收：从空数据库启动后使用生成的本地管理员邮箱和密码登录，登录页不要求填写工作区；创建成员；成员修改密码后旧密码和旧会话均失效，新密码可登录。无需平台账号。

AI 验收补充：右下角入口在手机展开为全屏面板；BOM 详情显示“AI 审查 BOM”。无模型配置时显示明确错误，不显示模拟结果；配置测试接口后审查结果引用真实 BOM 行，虚构行 ID 被拒绝，旧版本结果不作为当前结果展示。发布仍须人工执行。
